# Citing Awesome Echocardiography

If Awesome Echocardiography helps your research, teaching, benchmark setup, or literature review, please cite the repository.

## Recommended citation

> Awesome Echocardiography Maintainers. **Awesome Echocardiography: a curated research index for AI in echocardiography.** 2026. https://github.com/wangrui2025/awesome-echocardiography

## BibTeX

```bibtex
@misc{awesome_echocardiography_2026,
  author       = {{Awesome Echocardiography Maintainers}},
  title        = {Awesome Echocardiography: A Curated Research Index for AI in Echocardiography},
  year         = {2026},
  howpublished = {GitHub repository},
  url          = {https://github.com/wangrui2025/awesome-echocardiography},
  note         = {Website: https://awesome-echocardiography.vercel.app}
}
```

## Machine-readable citation

GitHub can read [`CITATION.cff`](CITATION.cff) and expose a **Cite this repository** action.

## DOI policy

This repository does not claim a DOI unless a real archival record has been minted by a service such as Zenodo.

If a Zenodo DOI is created later, prefer the real archived DOI/version for formal citation and update both this guide and `CITATION.cff`. Never invent or pre-allocate a DOI in citation metadata.
