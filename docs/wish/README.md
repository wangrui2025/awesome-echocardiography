# Awesome Echocardiography Wish

This folder stores this site's **site-specific current product intent**.

Shared Wish lifecycle/versioning is owned centrally at:

https://github.com/mykcs/.codex/blob/main/website-governance/WISH_PROTOCOL.md

Local files:

- `LATEST.md` - current site Wish;
- `DESIGN.md` - how that Wish maps to this site's curation/product/information architecture;
- `ARCHIVE.md` - superseded site Wishes and replacement reasons.

Do not copy the full cross-site Wish protocol back into this repository. This repository owns the current Wish content; `.codex` owns the shared Wish mechanism.
