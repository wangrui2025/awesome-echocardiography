# 当前愿望

更新：2026-09-21

> **我希望 Awesome Echocardiography 成为人工智能超声心动图研究者一个可信、克制、可复查的入口：让人能快速找到真正相关的论文、数据集、实际可用的代码和一致的评估方法，并且清楚分辨项目主页、真正代码仓库、占位实现、指标定义和仍然未知的东西。**

优先保护三件事：

- **质量和可信度高于收录数量。** 这是 curated research resource，不是为了“全”而全的论文列表。
- **代码状态必须说实话。** 项目主页、论文仓库、真正实现仓库、coming soon / placeholder 不能混为一谈。
- **评估标准服务整个领域。** Metrics 和 reference implementation 应保持 field-neutral，不围绕本站作者自己的论文建立偏心规则。

这个网站不应该变成作者作品展示页、论文链接农场或没有语义审查的排行榜。
